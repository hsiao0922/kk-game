# 小小魔法師闖鬼屋

小里肌（8 歲）原創漫畫角色的橫向跑跳小遊戲，共 3 關。主角是小小魔法師（小里肌本人的蠟筆風造型），也可以換成顆顆／顆力；遊戲裡會遇到顆顆、顆力、角角、容容。主角可以選小魔法師（揮魔術棒放星星、撿魔術道具）或原本的貓咪。

- 角色和故事：小里肌
- 上色和補畫動作：Gemini
- 遊戲程式：Claude

操作：電腦用 A D 或方向鍵走、空白鍵跳、滑鼠左鍵放魔法星星；手機平板用左半邊按住拖曳走路，右下的跳、魔法按鈕。
